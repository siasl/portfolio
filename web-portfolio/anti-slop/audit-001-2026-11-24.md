# Anti-Slop Audit 001 (2026-11-24, combined)

**Project:** Silas Howe Web Portfolio (`web-portfolio`)
**Mode:** After (read-only audit; no source files modified)
**Scope:** Combines the first pass with a second pass made the same day (no source changed in between). Second-pass findings are 14 to 17; earlier MEDIUM and LOW items were renumbered to follow them.
**Checks run:** Full source read (`index.html`, `tailwind.config.js`, `src/**/*`), WCAG 2.x contrast computation, static asset/usage scan, `npm run build` (PASS), `npm run lint` (FAIL), React Router `createHashHistory` source check.

## What Already Holds Up

Before listing issues, the site already avoids the worst AI-slop defaults:

- **Distinct identity:** Warm paper (`#F4F1EA`) and warm charcoal (`#181715`) with a single print-red accent (`#B5472B` / `#E47456`) and Newsreader + National Park typography.
- **Honest content:** Real projects, authentic personal voice, and explicit caveats where metrics are estimates (`Pretty Pulses`) or untested clinically (`Call Light`).
- **Functional theme toggle:** Light/dark mode persists via `localStorage`, respects `prefers-color-scheme`, and prevents flash on first paint.
- **Varied structure:** Asymmetric project spans (`7/5` and `5/7` in `WorkGrid`), mixed split/stack layouts across `CaseStudy` and `CreativeCode`, and zero em dashes in visible UI copy.

Priority maps directly to rule tier: **HIGH** = Hard Gate, **MEDIUM** = Purpose-Gate, **LOW** = Quality Locks and companion skills (`antislop-ui`, `antislop-human`, `antislop-layoutmobile`, `antislop-copywriting`, `antislop-code`).

### HIGH (Hard Gate)

1. **[R-37] Missing `DESIGN.md` and declared liveliness dials (`ENERGY / RHYTHM / MOTION`).**
   No `DESIGN.md` exists to anchor future `during`-mode work, and `walkthrough.md` still describes an abandoned "Ski Resort Neobrutalism" site that conflicts with the current editorial design.

2. **[R-39] Missing base-layer `cursor: pointer`, disabled cursor, and `:active` states on controls.**
   `src/index.css` does not set `cursor: pointer` on enabled interactive elements (Tailwind preflight resets `<button>` to `cursor: default`) or `cursor: not-allowed` on disabled controls, and buttons/links across `SiteHeader`, `MockupControls`, `SketchEmbed`, `Lightbox`, and `StoryMedia` lack distinct `:active` feedback.

3. **[R-39] Looping motion longer than 5 seconds runs without a pause control on Home and `PreviewVideo` embeds.**
   `PreviewVideo` (`src/components/PreviewVideo.tsx`), the homepage cards (`WorkGrid.tsx` for Call Light, Pretty Pulses, Recipe Agent, Do Board; `MakingSection.tsx` for Book Arts, XR, Jibbitz, and compact `SILAS Loop`), and `CreativeCode.tsx` recordings loop continuously past 5 seconds with no user pause control (only `CaseStudy.tsx` wraps mockups in `MockupControls`).

4. **[R-39] Unlabeled `<nav>` landmarks, missing skip link, and noisy screen-reader link names on animated cards.**
   `CaseStudy.tsx:160` and `CreativeCode.tsx:129` omit `aria-label` on secondary `<nav>` elements; `Layout.tsx`/`SiteHeader.tsx` lack a skip-to-main link; `WorkGrid.tsx` wraps full fake-UI DOM trees (`CallLightPreview`, `PrettyPulsesPreview`, `RecipeAgentPreview`) inside `<Link>` without `aria-hidden="true"`, leaking fake strings ("Room 204", "CP_1234", "LINKED JIRA") into the link's accessible name; `StoryMedia.tsx:59` passes `caption?.toString()` to video `aria-label` (risks `[object Object]` for ReactNode captions) and line 85 generates awkward `"Snapcode for the Farm Animal"` alt text.

5. **[R-32] No custom `:focus-visible` indicator and incomplete modal/menu keyboard handling.**
   `src/index.css` defines no `:focus-visible` ring (relying on browser defaults that can fail 3:1 contrast across light paper, dark charcoal, and the `#0B0B0C` Hero); `SiteHeader.tsx:76-98` mobile menu does not close on `Escape` or return focus to the toggle; `Lightbox.tsx:50-78` lacks a focus trap so `Tab` escapes behind the fullscreen modal.

6. **[R-03] Under-sized tap targets (< 44x44px) and two-state grid jumps on mobile/tablet.**
   Interactive targets fall below 44x44px across `SiteHeader.tsx` (`ThemeToggle` ~34x34px, `Menu` button unpadded), `MockupControls.tsx` (`py-1`, ~28px tall with 6px gap), `SketchEmbed.tsx` toolbar links (~18px tall), `Lightbox.tsx` controls (~22px tall), and page back/jump links (`CaseStudy.tsx:102`, `CreativeCode.tsx:64,111`, `PhotoVideo.tsx:21,27-28`); `PhotoVideo.tsx:50` and `StoryMedia.tsx:104` jump straight from 1 column to 3 columns at `640px` with no 2-column tablet state; card titles in `WorkGrid.tsx`, `MakingSection.tsx`, `CaseStudy.tsx`, and `CreativeCode.tsx` use `hover:text-accent` instead of `group-hover:text-accent`.

7. **[R-25] Verified WCAG AA color contrast failures (site UI and dark mode).**
   - `src/index.css:47-50`: dark-mode `::selection` (`#FFFFFF` on `#E47456`) is **3.03:1** (fails 4.5:1 normal text).
   - `src/components/previews/CallLightPreview.tsx:142`: `AckSequence` inactive step text (`ink/40` = `#9E9B96` on `#F4F1EA`) is **2.46:1** (fails both 4.5:1 and 3:1).
   - `src/components/SketchEmbed.tsx:251,274`: accent hover link (`#B5472B`) on `#EBE7DD` placeholder surface is **4.36:1** (fails 4.5:1).
   - `src/components/previews/MockupControls.tsx:22,30` & `src/components/StoryMedia.tsx:21`: button boundaries use `ring-line` (**1.32:1** light / **1.53:1** dark, fails 3:1 non-text contrast).

8. **[R-25] Verified WCAG AA color contrast failures inside code-built product reconstructions.**
   - `src/components/previews/RecipeAgentDemo.tsx:242,263,274`: Trace panel text `white/40` (**3.83:1**), `white/35` (**3.21:1**), and `white/30` (**2.68:1**) on `#14141A` all fail 4.5:1; Telegram link/label colors `#4FAE4E` on `#E1FEC6` (**2.56:1**) and `#168ACD` on `#E1FEC6` (**3.46:1**) / `#FFFFFF` (**3.78:1**) fail 4.5:1.
   - `src/components/previews/PrettyPulsesPreview.tsx:114,153,210`: `#FFFFFF` on `#2DBE6C` (**2.42:1**) and `#0E8C7E` on `#FFFFFF` (**4.14:1**) fail 4.5:1.

9. **[R-40] Hero image missing `fetchPriority="high"` and intrinsic dimensions; unsized `<img>` elements risk CLS.**
   `src/components/Hero.tsx:7-11` omits `fetchPriority="high"` and `width`/`height`; `AboutSection.tsx:42`, `StoryMedia.tsx:35`, `Lightbox.tsx:103`, and `WorkGrid.tsx:23` render `<img>` tags without `width`/`height` or an `aspect-ratio` container; `index.html:24-26` loads `Lexend` in the render-blocking Google Fonts stylesheet even though `National Park` is the primary sans font.

10. **[R-27] `SketchEmbed` iframe lacks an error or timeout state.**
    `src/components/SketchEmbed.tsx:227-249` displays `Loading {sketch.shortTitle}...` indefinitely if an external GitHub Pages embed is blocked, slow, or unreachable, with no fallback error message or retry action.

11. **[R-02] Em dashes (`—`) present in source code comments.**
    Five em dashes appear in comments: `src/components/PreviewVideo.tsx:13` and `src/components/previews/JibbitzPreview.tsx:48,50,52,376`. (No em dashes appear in user-facing UI text.)

12. **[R-23] Default Vite starter favicon and unused starter React SVG remain in the repo.**
    `index.html:6` still ships `/vite.svg` (`public/vite.svg`) as the site favicon instead of an intentional site mark or initial favicon, and `src/assets/react.svg` is unused template residue.

13. **[R-35] `npm run lint` fails due to ESLint v8 / flat-config mismatch.**
    `package.json` pins `eslint@^8.56.0` while `eslint.config.js` imports `eslint/config` (ESLint 9+), causing `npm run lint` to crash with `ERR_PACKAGE_PATH_NOT_EXPORTED`.

14. **[R-24 / R-26] In-page `#section` links resolve to the 404 page outside the click handler.**
    The site uses `HashRouter`, so the URL hash *is* the route. `href="#work"` produces `https://site/#work`, which React Router parses as the path `/work` (verified in `react-router` `createHashHistory`: a hash without a leading slash gets one prepended) and renders `NotFound`. The `onClick` + `preventDefault` hides this for a plain left click, but cmd/ctrl-click, middle-click, "open in new tab", "copy link", and sharing the URL all land on "Page not found".
    Affected: `SiteHeader.tsx:68,93` (all five main nav links), `PhotoVideo.tsx:27-28` (Photography / Video jump links), `CreativeCode.tsx:113` (all eight sketch jump links).

15. **[R-32 / R-39] Route changes do not move focus or announce the new page.**
    `Layout.tsx:15-22` scrolls to the top (or to the hashed section) on navigation but never moves focus. After a keyboard user activates a project card or "Next project", the focused link unmounts and focus drops to `<body>`, so the next `Tab` restarts from the header; screen readers get no signal that the page changed. The hash-section case scrolls the section into view but leaves focus on the old link too.

16. **[R-39] Mockup Pause button combines `aria-pressed` with a label that flips.**
    `MockupControls.tsx:17-24` sets `aria-pressed={paused}` and also swaps the label between "Pause" and "Play". A screen reader announces "Play reconstruction, toggle button, pressed" when paused: the pressed state and the label contradict each other. Use one mechanism (a fixed "Pause" label with `aria-pressed`, or a flipping label without it).

17. **[R-39] Looping preview videos drop the alt text their tiles define.**
    `MakingSection.tsx:109-110` renders `PreviewVideo` for items with a `loop` (Book arts pop-up spread, XR farm-animals lens) but never passes `item.alt`, and `PreviewVideo.tsx:38` is `aria-hidden="true"`. The written descriptions on lines 27 and 64 never reach assistive tech; the link's accessible name is only "Book arts →" / "XR →". Same gap for the Do Board lead (`AnimatedLead.tsx:31-37`). Related: `PhotoVideo.tsx:13,35,42` falls back to `alt=''`, so any photo missing alt becomes a button named "Enlarge image: " with nothing after it.

23. **[R-07] Dot-grid backgrounds in Telegram chat mockups have no written identity reason.**

24. **[R-04] Unused `PrettyPulsesPanel` imports generic AI icons (`Sparkles`, `Zap`) from Lucide.**
